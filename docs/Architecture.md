# Architecture reference

Magic Compact applies shared policy to host-native records and writes a verified successor, leaving the source and its children unchanged. [Core](Core.md) defines the behavior and safety guarantees; [OpenCode](OpenCode.md) specifies host flows and [Development](Development.md) maps the implementation and maintenance commands.

The [lifecycle diagrams](diagrams/state-machines.html) show successor readiness, generation cleanup, and retention retries. The inventory below covers the other stateful boundaries as well. Its stages describe behavior, not necessarily persisted enum values. Source paths are relative to [`packages/opencode-plugin/`](../packages/opencode-plugin/), except release paths.

## State-machine inventory

| Machine and owner                                                                                                                                                                                                                                                                                                             | Stages and invariants                                                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Source admission: [`compact/successor.ts`](../packages/opencode-plugin/src/compact/successor.ts), [`v2/session.ts`](../packages/opencode-plugin/src/v2/session.ts)                                                                                                                                                            | Read the root and live tree; compact and trim require strict at-rest history. Recovery collects recoverable stored records under the same live checks. Busy or unknown state, pending questions or permissions, revert and compaction refuse. Never infer abandonment from age or idleness; recheck before ready.                                                 |
| Successor: [`compact/successor.ts`](../packages/opencode-plugin/src/compact/successor.ts), [`v2/session.ts`](../packages/opencode-plugin/src/v2/session.ts)                                                                                                                                                                   | Prepared edits → create → replay/import → cache and stats → source and candidate recheck → ready attempt → verified. Before ready, cleanup may delete, report residue, find absent, or keep the candidate. A possibly applied ready update is kept. Absence proves neither deletion nor storage ownership.                                                        |
| Exclusivity: [`policy/successor.ts`](../packages/opencode-plugin/src/policy/successor.ts)                                                                                                                                                                                                                                     | One process owns an operation on a source until release. A second in-process operation refuses; fresh comparisons do not lock out other processes.                                                                                                                                                                                                                |
| V1 replay: [`compact/fork.ts`](../packages/opencode-plugin/src/compact/fork.ts)                                                                                                                                                                                                                                               | Plan → native fork cut → empty check → ordered replay → verify fork and source. Boundary history reads retry once only on rejection or timeout; invalid responses are final. The owning request deletes a partial fork and names it if deletion fails. Rewritten IDs and links preserve order.                                                                    |
| Background delivery: [`policy/recovery.ts`](../packages/opencode-plugin/src/policy/recovery.ts)                                                                                                                                                                                                                               | A launch is owed one later matching delivery or an explicit abandoned marker. Settlement is FIFO: two launches need two deliveries, and an earlier delivery settles neither. Unsupported or active work refuses.                                                                                                                                                  |
| Recovery: [`magic-recover.ts`](../packages/opencode-plugin/src/magic-recover.ts), [`v2/recover.ts`](../packages/opencode-plugin/src/v2/recover.ts)                                                                                                                                                                            | Unfinished stored records become native interrupted copies or cause refusal; a complete model-visible recovery context accompanies the verified successor. Recovery neither stops work nor invents results. OpenCode 2 subagent records have a separate documented scope.                                                                                         |
| V1 ownership: [`compact/owned.ts`](../packages/opencode-plugin/src/compact/owned.ts)                                                                                                                                                                                                                                          | Register a known fork before population and block native compaction; abort on failure and delete. Unregister only on confirmed deletion; a failed deletion keeps the guard and names the fork.                                                                                                                                                                    |
| V2 ownership: [`v2/owned.ts`](../packages/opencode-plugin/src/v2/owned.ts)                                                                                                                                                                                                                                                    | Register the owned request, permit one response, close and settle removal. Failed removal fails and names the session. A session reported missing retains its guard and is named alongside another failure, but does not alone fail a validated request. In-flight writes and cleanup settle before completion.                                                   |
| Generation pool: [`policy/generation-pool.ts`](../packages/opencode-plugin/src/policy/generation-pool.ts), [`v2/generation.ts`](../packages/opencode-plugin/src/v2/generation.ts)                                                                                                                                             | Admit at most five requests, each owning one target. The first failure stops admission before cleanup; all active workers drain. Discard all results on failure and report unconfirmed removals.                                                                                                                                                                  |
| Retention: [`retention/retention.ts`](../packages/opencode-plugin/src/retention/retention.ts), [`retention/classifier.ts`](../packages/opencode-plugin/src/retention/classifier.ts), [`retention/backends.ts`](../packages/opencode-plugin/src/retention/backends.ts)                                                         | No candidates require no key or request. Otherwise check the key, summarize and admit at most four candidate requests. A potentially retryable 400 pauses admission at headers while classified; an eligible 503 waits without a slot. Terminal failure stops admission, drains and discards decisions. Only the documented excerpt and OpenAI 503 retries apply. |
| Model selection and fit: [`policy/reasoning.ts`](../packages/opencode-plugin/src/policy/reasoning.ts), [`policy/budget.ts`](../packages/opencode-plugin/src/policy/budget.ts), [`compact/batch.ts`](../packages/opencode-plugin/src/compact/batch.ts), [`v2/summarizer.ts`](../packages/opencode-plugin/src/v2/summarizer.ts) | Use the configured summarizer, optionally selecting a matched model in preflight. A match that cannot fit falls back before any request; impossible configured fit refuses. There is no runtime model failover. Unknown reasoning replay remains unknown.                                                                                                         |
| Generation identity: [`policy/generation.ts`](../packages/opencode-plugin/src/policy/generation.ts), [`compact/compact.ts`](../packages/opencode-plugin/src/compact/compact.ts)                                                                                                                                               | Plan with a conservative marker, fit the exact prompt and unique nonce, insert the marker and validate the untrusted response. Wrong count, ordinal, marker, image coverage or nonce leak refuses before successor creation.                                                                                                                                      |
| Checkpoints and turns: [`compact/plan.ts`](../packages/opencode-plugin/src/compact/plan.ts), [`policy/turns.ts`](../packages/opencode-plugin/src/policy/turns.ts), [`policy/protocol.ts`](../packages/opencode-plugin/src/policy/protocol.ts), [`policy/lineage.ts`](../packages/opencode-plugin/src/policy/lineage.ts)       | Validate the selected native checkpoint, derive effective complete turns, preserve the tail and exclude opaque summaries from targets. Invalid selected checkpoints refuse; native accounting has a separate view.                                                                                                                                                |
| Media projection: [`compact/media.ts`](../packages/opencode-plugin/src/compact/media.ts), [`v2/media.ts`](../packages/opencode-plugin/src/v2/media.ts), [`policy/media.ts`](../packages/opencode-plugin/src/policy/media.ts)                                                                                                  | Validate the image manifest and derive a request-only placeholder only when strictly smaller; otherwise retain the original. A changed image cohort fails closed and source file bytes remain stored.                                                                                                                                                             |
| Replay attribution: [`compact/reasoning.ts`](../packages/opencode-plugin/src/compact/reasoning.ts), [`v2/reasoning.ts`](../packages/opencode-plugin/src/v2/reasoning.ts)                                                                                                                                                      | Index source units as attributable or unknown, then estimate selected subsets. Repeated or incomplete units cannot be counted as certain; V2 reports unknown. Replay estimates remain separate from stored pruning and cached-read statistics.                                                                                                                    |
| Omission cache: [`storage/omission.ts`](../packages/opencode-plugin/src/storage/omission.ts), [`storage/store.ts`](../packages/opencode-plugin/src/storage/store.ts)                                                                                                                                                          | Plan IDs, serialize per-key mutations and persist the cache; reads require authorization and integrity. Invalid or ambiguous legacy data is quarantined or refused. Failures do not expose paths or content.                                                                                                                                                      |
| Stats: [`storage/stats.ts`](../packages/opencode-plugin/src/storage/stats.ts), [`stats/events.ts`](../packages/opencode-plugin/src/stats/events.ts), [`stats/pricing.ts`](../packages/opencode-plugin/src/stats/pricing.ts)                                                                                                   | Absent or saved totals → serialized completion update or successor derivation → atomic write and notice. Pruning, media projection and cached-read accounting remain separate. Invalid saved totals remain unchanged and stop commands that need them with a content-free diagnostic.                                                                             |
| Feedback and navigation: [`toast-v1.ts`](../packages/opencode-plugin/src/toast-v1.ts), [`tui-v1.ts`](../packages/opencode-plugin/src/tui-v1.ts), [`tui-v2.ts`](../packages/opencode-plugin/src/tui-v2.ts)                                                                                                                     | Progress → terminal feedback; a late successful progress settlement triggers best-effort terminal reassertion. A ready event navigates once only if the TUI still shows the source. Toast failure cannot change the operation.                                                                                                                                    |
| Compaction evaluation: [`eval/compaction/`](../packages/opencode-plugin/eval/compaction/)                                                                                                                                                                                                                                     | Run-owned root and artifact → attempts and sessions → storage and cleanup events → report. Cleanup requires ownership and source/successor dependencies; leftovers and unresolved evidence remain identifiable. See [Compaction evaluation](CompactionEvaluation.md).                                                                                             |
| Decision evaluation: [`eval/decisions/`](../packages/opencode-plugin/eval/decisions/)                                                                                                                                                                                                                                         | Plan → paid attempt → recorded outcome or interruption → validated report. Preserve paid records and frozen cohort contracts across interrupted work. See [Decision evaluation](DecisionEvaluation.md).                                                                                                                                                           |
| Release: [`scripts/release-opencode.sh`](../scripts/release-opencode.sh), [publish workflow](../.github/workflows/publish-opencode.yml)                                                                                                                                                                                       | Version, commit and tag → push → remote checks → npm publish → GitHub release. Resume an interruption only after inspecting local and remote state; the tag identifies the committed manifest.                                                                                                                                                                    |
